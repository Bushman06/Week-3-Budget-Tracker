# SpendWise – Personal Budget and Expense Tracker

## 1. Project Description

SpendWise is a personal budget and expense tracking web application designed to help users manage their money, monitor spending, and make better financial decisions.

The application provides a dashboard where users can view their monthly income, total expenses, remaining balance, budget progress, and expenses by category.

Users can also add and manage expenses, set a monthly budget, view recent transactions, and customize their experience through the Settings page.

The application includes a dark mode feature and personal information management to provide a more convenient user experience.

## 2. Project Features

- Personal finance dashboard.
- Monthly budget management.
- Add and manage expenses.
- Expense categories such as Food, Transport, Rent, Entertainment, Savings, and Utilities.
- Automatic expense and balance calculations.
- Budget progress tracking.
- Recent transactions display.
- Personal information management.
- Light mode and dark mode.
- Responsive website layout.
- Local storage for saving application data.

## 3. Technologies Used

The project was developed using the following technologies:

- **HTML5:** Provides the structure and content of the application.
- **CSS3:** Handles website styling, layouts, responsiveness, and dark mode.
- **JavaScript:** Adds functionality, calculations, conditionals, arrays, DOM manipulation, and event handling.
- **Local Storage:** Saves user information, expenses, budget information, and appearance preferences in the browser.
- **Git:** Used for version control and tracking project changes.
- **GitHub:** Used to store and manage the project repository.
- **Netlify:** Used to host and deploy the live website.

## 6. Deployment Process Summary

The project was deployed using GitHub and Netlify.

The deployment process involved the following steps:

1. Completed the SpendWise application locally using HTML, CSS, and JavaScript.
2. Organized the project files into the correct folder structure.
3. Created and updated the project repository on GitHub.
4. Committed and pushed the latest project changes to the main branch.
5. Created a Netlify account.
6. Connected the GitHub repository to Netlify.
7. Selected the main branch for deployment.
8. Configured the project root directory as the publish directory.
9. Deployed the application and received a public Netlify URL.
10. Opened the live website to check that it was accessible.

### Automatic Deployment

Netlify was connected to the GitHub repository to support automatic deployments.

When changes are committed and pushed to the connected GitHub branch, Netlify can automatically start a new deployment.

This makes it easier to maintain and update the live website without manually uploading the project files each time.
